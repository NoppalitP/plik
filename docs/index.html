ชีวิตการพิมพ์แบบเดิม (Without Plik)
  • • พิมพ์ข้อความยาวใน LINE/Slack: ;yo8nvgik9hv'dkifhk... แล้วกด Enter ไปแล้ว ต้องตามขอโทษเพื่อนร่วมงาน
  • • ต้องคอยก้มมอง Taskbar ว่าตอนนี้เครื่องเป็นภาษาไทยหรืออังกฤษ
  • • พิมพ์คำว่า นะค่ะ หรือ กระเพรา ติดเป็นนิสัย เสียภาพลักษณ์มืออาชีพ
  • • โปรแกรมสลับภาษาทั่วไปชอบไปเปลี่ยนโค้ดหรือชื่อตัวแปรใน VS Code ทำให้ build พัง
เมื่อมี Plik (With Plik Installed)
  • • พิมพ์อะไรก็ออกเป็นภาษานั้นทันที Plik พลิกคำผิดให้ตั้งแต่ตัวอักษรที่ 3 ลื่นไหลเหมือนคุยกับสมอง
  • • ลืมปุ่ม Grave Accent (~) หรือ Alt+Shift ไปได้เลย โฟกัสกับเนื้อหาอย่างเดียว
  • • คำผิดยอดฮิต เช่น นะคะ, กะเพรา, the ได้รับการแก้ให้ถูกต้องโดยอัตโนมัติ
  • • มีระบบ Syntax Guard คอยคุ้มครอง VS Code, Terminals, คำสั่ง git, .sh โค้ดไม่เพี้ยน 100%

N-gram Scorer
